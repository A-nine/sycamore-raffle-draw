FAQs

      
What does the pool hash prove?
Before any winner is drawn, the ordered list of slots is frozen and hashed with SHA-256. If a single slot were added, removed or reordered afterwards, the hash would change. The hash is shown on the live stage, so everyone sees it before the draw.

      
How is the winner picked?
The browser’s cryptographically secure random number generator (crypto.getRandomValues) returns a 32-bit number. Values that would bias the result are thrown away (rejection sampling), and the winning index is that number modulo the count of eligible slots.

      
Why are names shortened?
To protect entrants’ privacy, the public pool keeps only first names, last initials and masked tags such as @ada•••89. Emails and identifiers are never published.

      
What does “without replacement” mean?
Once someone wins, all of their slots are removed before the next round, so each person can win only once. The verifier applies the same rule.
